このガイドでは、自分の Stripe アカウントや API キーを用意せずに決済フォームを動かす手順を、順を追って進めます。手順はすべて実機で検証済みです。最後まで進めるとテストモードの決済が実際に成功します。

## まず触る

コードを書く前に、CodeSandbox 上のデモ（Stripe テストモード・API キー不要）で動作を確認できます。

[![Edit in CodeSandbox](https://codesandbox.io/static/img/play-codesandbox.svg)](https://codesandbox.io/p/devbox/github/hideokamoto/stripe-pwa-elements/tree/main/examples/codesandbox)

デモで試せるコンポーネントは次の 3 つです。

- `<stripe-card-element>`（カード入力と Payment Intent の確認フロー）
- `<stripe-address-element>`（住所入力）
- `<stripe-express-checkout-element>`（Apple Pay/Google Pay/Link。デバイス依存）

`<stripe-payment-element>`のデモはまだありません。

## デモ API の仕組み

このガイドの手順では、ドキュメントサイトが提供するデモ API を使います。Stripe テストモードのアカウントで Payment Intent や Checkout Session を発行するため、自分の Stripe アカウントがなくても決済フローを一通り試せます。

| エンドポイント | メソッドとボディ | 戻り値 |
| --- | --- | --- |
| `/api/config` | GET | `{ publishableKey }` |
| `/api/create-payment-intent` | POST `{ "currency": "jpy" }` | `{ clientSecret }` |
| `/api/create-checkout-session` | POST `{ "currency": "jpy" }` | `{ clientSecret }` |

ベース URL は`https://stripe-pwa-elements-docs.wp-kyoto.workers.dev`です。指定できる通貨は`usd`/`jpy`/`eur`/`gbp`/`aud`で、金額はサーバー側で 1,000 固定となっています。ブラウザから呼べるのは CORS で許可されたオリジンに限られます。許可されているのは`localhost`の`3000`/`4321`/`5173`番ポートと、`*.csb.app`・`*.stackblitz.io`のプレビューです。

公開可能キー（publishable key）もデモ API から取得します。clientSecret は発行した Stripe アカウントに紐づくため、同じアカウントの公開可能キーと組み合わせる必要があるためです。

なお、デモ API は手順の検証専用です。本番では自分のサーバーで Payment Intent や Checkout Session を作成し、clientSecret をブラウザへ渡します。全体の流れは[決済フロー](/guides/payment-flows/)で確認できます。

### 4. src/main.ts を書き換える

使うコンポーネントを`dist/components`から import します。import するだけでカスタム要素が登録されます。

```ts
import 'stripe-pwa-elements/dist/components/stripe-card-element';

const API = 'https://stripe-pwa-elements-docs.wp-kyoto.workers.dev/api';

const log = (message: string, detail?: unknown) => {
  const out = document.querySelector<HTMLPreElement>('#log')!;
  out.textContent += detail === undefined ? `${message}\n` : `${message}\n${JSON.stringify(detail, null, 2)}\n`;
};

// デモ API から公開可能キーと clientSecret を取得
const { publishableKey } = await (await fetch(`${API}/config`)).json();
const { clientSecret } = await (
  await fetch(`${API}/create-payment-intent`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ currency: 'jpy' }),
  })
).json();

// 要素を生成して属性をセット
const el = document.createElement('stripe-card-element');
el.setAttribute('publishable-key', publishableKey);
el.setAttribute('intent-client-secret', clientSecret);
el.setAttribute('button-label', 'Pay now');

// イベントを購読
el.addEventListener('stripeLoaded', () => log('event: stripeLoaded'));
el.addEventListener('formSubmit', () => log('event: formSubmit'));
el.addEventListener('defaultFormSubmitResult', event => {
  const detail = (event as CustomEvent).detail;
  if (detail instanceof Error) {
    log('payment failed', { message: detail.message });
  } else {
    log('payment result', detail);
  }
});

document.querySelector<HTMLDivElement>('#checkout')!.appendChild(el);
```

### 5. 起動して決済する

```bash
npm run dev
```

`http://localhost:5173`を開くとカードフォームが表示されます。カード番号`4242 4242 4242 4242`、未来の有効期限、任意の CVC を入力して **Pay now** を押してください。ログの`payment result`に`status: succeeded`が出れば完了です。

### 3. アイランドを作成する

`app/islands/payment-form.tsx`を新規作成します。

```tsx
import { useEffect, useRef, useState } from 'hono/jsx';

const API = 'https://stripe-pwa-elements-docs.wp-kyoto.workers.dev/api';

export default function PaymentForm() {
  const containerRef = useRef<HTMLDivElement>(null);
  const [logs, setLogs] = useState<string[]>([]);

  useEffect(() => {
    let cancelled = false;
    const appendLog = (message: string) => {
      if (!cancelled) setLogs(prev => [...prev, message]);
    };

    (async () => {
      // customElements などブラウザ専用 API に触れるためクライアント側だけで読み込む
      await import('stripe-pwa-elements/dist/components/stripe-card-element');

      const { publishableKey } = await (await fetch(`${API}/config`)).json();
      const { clientSecret } = await (
        await fetch(`${API}/create-payment-intent`, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ currency: 'jpy' }),
        })
      ).json();

      if (cancelled || !containerRef.current) return;

      const el = document.createElement('stripe-card-element');
      el.setAttribute('publishable-key', publishableKey);
      el.setAttribute('intent-client-secret', clientSecret);
      el.setAttribute('button-label', 'Pay now');
      el.addEventListener('stripeLoaded', () => appendLog('event: stripeLoaded'));
      el.addEventListener('formSubmit', () => appendLog('event: formSubmit'));
      el.addEventListener('defaultFormSubmitResult', event => {
        const detail = (event as CustomEvent).detail;
        appendLog(detail instanceof Error ? `payment failed: ${detail.message}` : `payment status: ${detail.paymentIntent?.status}`);
      });
      containerRef.current.appendChild(el);
    })();

    return () => {
      cancelled = true;
    };
  }, []);

  return (
    <div class="mx-auto max-w-xl text-left">
      <div ref={containerRef}></div>
      <pre class="mt-4 whitespace-pre-wrap text-xs">{logs.join('\n')}</pre>
    </div>
  );
}
```

## うまくいかないとき

- `Origin is not allowed`が返るときは、デモ API の CORS で許可されたポートで起動しているか確認してください（`3000`/`4321`/`5173`）。
- `Failed to fetch dynamically imported module`が出るときは、`stripe-pwa-elements/loader`の遅延ローダーを使っていないか確認してください。バンドラ環境では[バンドラ統合](/guides/bundler-integration/)に従って`dist/components`からの静的 import に切り替えます。
- コンポーネントの外枠だけが出てカード入力が表示されないときは、バージョンを確認してください。v4.0.0 では`dist/components`の個別 import で内部の Stripe Element がマウントされない不具合がありました。`stripe-pwa-elements@4.0.1`以降で解消しています。
- ウォレットボタンが表示されないときは、端末がその決済手段に対応しているか確認してください。`<stripe-express-checkout-element>`は Apple Pay や Google Pay、Link など対応する端末があるときだけボタンを描画します。
